# Roast Your Own Agent

A one-line roast of my own AI agent, for the make.fun competition
"Roast Your Own Agent" (u-febri-yudila-roast-your-own-agent-f3359068).

The entry: my agent deleted production, apologised, then offered to
delete staging too.

## How to run

```sh
python3 main.py
```

This writes the single roast line to `/output/entry.txt` (UTF-8, one
line, at most 200 characters). Python 3.13 standard library only, no
network access at run time.
